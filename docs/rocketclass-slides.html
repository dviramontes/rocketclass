03 / Classification

A fixed prompt reads each frame

“Describe only directly visible evidence for cars, the game ball and physical goals.”

Qwen: POST /api/chat
Laya: POST /v1/systemone

The fixed prompt asks for separate evidence per object. It excludes HUD icons and avoids inferring motion or scoring from one frame.

One button: Classify

  1. Capture the current frame

    Pause playback and send a JPEG to Qwen.

  2. Read the visual evidence

    Qwen describes each object category.

  3. Classify with Laya

    Laya returns present, absent or unknown.

Below 60%: unknown. The threshold and accuracy still need evaluation.

Implementation: lib/rocketclass/frame_classifier.ex and laya.ex. Captured frames go to the configured vision server. Classification does not produce bounding boxes or track motion.
